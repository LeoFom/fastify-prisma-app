# C0.3 — повторна перевірка та очищення конфігурації

Дата: 24.11.2026. Репозиторій: Coffeo API. Робоча гілка застосунку: `dev`; `main` містить стару версію.

## Виконано

- У `main/src/config/env.ts` значення історичних MongoDB, Gmail, JWT і PostgreSQL credentials замінені читанням server environment variables. Імена експортів та налаштування тривалості токенів збережені.
- Для JWT access/refresh і DATABASE_URL немає вбудованого fallback: відсутнє або порожнє значення зупиняє завантаження конфігурації.
- У поточному `dev` старий `src/config/env.ts` відсутній; MongoDB-клієнт у поточному застосунку не використовується.
- Доступи та паролі до цього документа не включені.

## Рішення власника та залишковий статус

| Доступ | Підтверджений статус |
| --- | --- |
| Стара MongoDB | Власник вирішив видалити MongoDB. Фактичне видалення кластера/користувача незалежно не перевірене; рішення не зараховане як підтверджене відкликання |
| Gmail app password | За рішенням власника відкликання відкладено. Видалення literal із коду не відкликає доступ до Google-акаунта |
| Старі JWT-ключі | Прибрані з актуального конфіг-файлу main; заміна в усіх можливих старих deployment не підтверджена |
| Стара локальна PostgreSQL | Literal прибраний; стан старого локального кластера та повторне використання пароля не перевірені. Старий URL не належав поточному Neon |

Технічне очищення не є твердженням, що всі доступи відкликані або що їх ніхто не використовував. У разі повторного використання старих значень потрібно замінити їх у відповідних активних сервісах. Поточні deployment credentials не змінювалися.

## Перевірки та межі

- TypeScript transpile зміненого старого конфігу: без syntax diagnostics.
- Виконання зі синтетичними env: значення читаються з env; для трьох обов'язкових параметрів перевірена відмова за відсутності; порожній JWT-ключ відхиляється; MongoDB/пошта за замовчуванням порожні.
- Раніше виконаний обмежений scan локального поточного коду: 51 API та 130 web файлів, без збігів вибраних шаблонів credential URI/provider tokens. Це не повний secret scan і не скан усієї історії.
- Повна збірка старої main, продуктові тести й CI для цієї зміни не виконувались. На main немає workflow CI. Робочий код dev не змінюється цією правкою.
- Переписування Git history, видалення баз/акаунтів та зміна секретів у провайдерів не виконувалися. Історичні коміти й сторонні копії можуть містити старі значення.

GitHub не вимагає окремого запису паролів чи токенів. Цей документ фіксує лише виконані дії та статус. Для реального відкликання потрібна дія в сервісі; стирання коду не достатньо: [рекомендації GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository).

Підсумковий статус C0.3: повторна перевірка й очищення конфігурації виконані; повне відкликання історичних доступів не підтверджене. Наступні кроки плану автоматично не розпочаті.
